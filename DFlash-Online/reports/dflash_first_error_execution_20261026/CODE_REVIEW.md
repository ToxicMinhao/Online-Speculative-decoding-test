Full-block attention, sampling and model arithmetic remain in the reviewed production implementation.

Passed temporary qualification states are retired only within this new run after compact evidence and hashes are written; failure tensors and foreign files are refused. The full tiny CPU integration checks all 35 retired tensors and their retained-evidence hashes, with before/after free space retained for every retirement batch. An additional integration test injects a C gradient-gate failure: only warmup/O/C start, C's failure state and the required O comparator states remain, no later qualification trial starts, and main training remains unstarted. The outer storage admission includes qualification, main state/export/initial evidence, failure and atomic overlap, staging and the required reserve. It does not assume retirement of old O/U/P/R artifacts.

Main training constructs only independent C/K/A trainers, validates released weights, empty Adam/counters and the full pinned RNG, runs the exact retained schedule for 128 steps per arm, and checks closure before constructing the native backend. Completed main accounting is 384 optimizer steps and 768 response presentations. Partial failures aggregate actual closure receipts; a missing active-arm receipt is explicitly unknown and leaves remaining-step accounting unavailable. There is no automatic retry. Correctness failures prevent later arms or evaluation; valid null or harmful results do not stop evaluation.

Fresh serving compares only O/C/K/A over 64 requests and three rotating repeats, totaling 768 generations. The first 96-generation serving check is inside this budget, separate from the zero-generation training qualification. Exact retained F tokens and termination and retained O verification counts remain gates. These affect validation, failure evidence and accounting, not the algorithms or settings. The earlier implementation-stage rejected-rerun report overwrite remains covered by its regression test.
