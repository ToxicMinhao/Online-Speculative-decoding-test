# Continuation-repair pilot

One fixed warm continuation of native C + K+PAIR, from authenticated PAIR1 to event 2. BASE is the retained PR60 CONTROL endpoint. TAIL changes only the allocation within the current HIGH repair pool; all LOW and preservation weights, HIGH mass, response normalization and optimizer settings remain unchanged.

The score is the running-minimum area of native BF16 follower-margin supports, with FP32 subtraction/reduction and a fixed denominator of14. Scores, roles and coefficients are detached. Three additive moments reuse the existing eight-block vocabulary projections and pool across the complete response. There is no new scoring forward, auxiliary loss or precision configuration.
