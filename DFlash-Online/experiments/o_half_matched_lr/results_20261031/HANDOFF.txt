Primary effect, with positive values favoring K_HALF:
  R = 100 * (sum C_O_HALF - sum C_K_HALF) / sum C_O_HALF.

Sums run over both fixed training seeds and all 128 shared requests. Report each seed separately too. The practical research-priority threshold is 0.5%; it is a chosen decision threshold, not a measured deployment break-even.

Mandatory secondary effects, using the same ratio-of-summed-calls definition:
  K versus O at LR 3e-4;
  K_HALF versus K (the LR change within K);
  O_HALF versus O (the LR change within O);
  every trained method versus F.

Also report the descriptive objective-by-LR interaction with a common denominator:
  I = 100 * [(C_O_HALF - C_K_HALF) - (C_O - C_K)] / C_F,
where each C is the pooled call total. Positive I means K's advantage over O is greater at the lower LR. Do not subtract differently normalized percentage reductions and label that the same interaction.

Uncertainty: 10,000 paired-request bootstrap draws with NumPy PCG64 seed 20261102 and linear 2.5/97.5 percentile endpoints. Resample 128 REQUEST IDENTITIES; each sampled identity carries both seeds and all methods. Use the same index matrix for every statistic and per-seed summary. Recompute ratios from summed counts in each draw. Do not treat 256 seed/request rows, repeats, or duplicated F records as independent units.

These are nominal, descriptive request-bootstrap intervals conditional on two fitted seeds and a reused development panel. They do not estimate population-level training-seed uncertainty, correct for earlier selection of K_HALF, or establish fresh held-out significance. Label secondary intervals descriptive/unadjusted.

Compute gross gains/harms relative to F WITHIN each seed before pooling:
  g_M[i] = max(C_F[i] - C_M[i], 0)
  h_M[i] = max(C_M[i] - C_F[i], 0)
  G_M = sum g_M; H_M = sum h_M; net saving = G_M - H_M.

For candidate A versus comparator B, decompose the same-request difference:
  retained_gain = sum min(g_A, g_B)
  lost_gain = G_B - retained_gain
  added_gain = G_A - retained_gain
  prevented_harm = sum max(h_B - h_A, 0)
  added_harm = sum max(h_A - h_B, 0)
  C_B - C_A = added_gain - lost_gain + prevented_harm - added_harm.

Apply this to K_HALF versus O_HALF and O_HALF versus O; include the retained K_HALF-versus-K decomposition for context. This distinguishes net repair from harm reduction and preserves the identity of requests. It does not uniquely identify gradient conflict, memorization or a preservation mechanism.

   The rule supports a useful point estimate plus a positive effect; it does

   Require the ENTIRE primary 95% interval to lie inside [-0.5%, +0.5%]. Report
   each seed. For the decision to prefer O_HALF, also require BOTH per-seed point
   effects to lie inside this band. If the pooled interval is inside but either
   seed's point effect is outside, report pooled equivalence and apply D because
   of seed heterogeneity. This consistency rule does not prove per-seed
   equivalence. Failure of superiority alone is not equivalence.
   Prefer ordinary O_HALF as the simpler provisional base for this setting and
   retire a claim of an established incremental K benefit here. If BOTH within-
   objective LR comparisons improve, the matrix supports lower LR as the shared
   recipe improvement. If they differ, report that interaction instead of
   attributing everything to LR. Further novelty must come from a new repair/
   preservation mechanism that improves on the strengthened ordinary baseline.

   Report the precise weaker conclusion: small directional effect, mixed seeds,

   do not call O_HALF/K_HALF equivalent or K superior without the corresponding

   one next action, explaining what uncertainty it would resolve and why that
   information would change the base or mechanism choice.

   concrete failure separately from algorithm efficacy; preserve failures and
